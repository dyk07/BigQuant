# 截面交叉注意力（Cross-Section Attention）A/B 实验

- **日期**：2026-10-17
- **模型**：`model_cnn.py` 的 `CNNTransformerModel`（`use_xsec=True` / `use_section_batch=True` / `use_grouped_batch=True` 变体）
- **原始日志**：[raw/full_base_xsec_ab.log](./raw/full_base_xsec_ab.log)（随机 batch baseline）、
  [raw/full_secbatch_ab.log](./raw/full_secbatch_ab.log)（截面 batch，无注意力）、
  [raw/full_xsec_ab.log](./raw/full_xsec_ab.log)（截面 batch + 注意力）、
  [raw/full_grouped_ab.log](./raw/full_grouped_ab.log)（分组大 batch + 注意力）
- **权重**：`checkpoints/full_base.pt`（baseline）、`checkpoints/full_secbatch.pt`（截面 batch）、
  `checkpoints/full_xsec.pt`（xsec）、`checkpoints/full_grouped.pt`（分组大 batch + xsec）

## 动机

比赛评估指标是**截面 Spearman IC**，而现有模型对每只股票**独立编码**，
输出天然是「绝对分数」而非「相对排序」。本次实验引入**截面交叉注意力**，
让同一时刻截面内的股票互相看到彼此，学习相对强弱。

## 实现方案

### 数据侧（`dataset.py`）
- 新增 `make_section_batches(meta)`：按 `(day, minute_of_day)` 分组，
  每个 batch = 一个完整截面（约 900–1000 只股票），无需 padding。
- 新增 `collate_sections()`：截面内 `torch.stack`，返回 `(X, y, 全局下标)`。
- `StockDataset` 增加 `return_idx`，供打乱截面顺序后的 `predict` 按原顺序还原。

### 模型侧（`model_cnn.py`）
- 新增 `CrossSectionAttention`：多头自注意力 + FFN + Pre-LN（可多层）。
- 放置位置：`pool` 之后（`[N, 2*hidden]` 池化向量），复杂度 `O(N²·d)`，
  而非 token 级 `O(N²·T²)`。
- 残差式拼接：`[原始表示 ‖ 截面上下文表示]` 送入 head，避免 attention
  抹掉个股自身信息。
- 不加入 per-instrument embedding（注意力对 N 维置换等变），保证测试集
  新股票可泛化。

### 训练侧（`train.py`）
- `use_xsec` 时用截面 batch；`corr` 损失（batch 内 Pearson）自动变为
  **该截面的 soft-IC**，与评估指标严格对齐。
- 单截面 batch 较小，用 `accum_steps`（默认 4）跨截面累积梯度。
- `--xsec` / `--accum-steps` 命令行开关；推理与训练用同一 `batch_sampler`，
  保证截面语义一致。

## 实验结果（bar30m，全量）

训练 2020–2023（48 个月，772.5 万样本），验证 2024H1（93.0 万样本）。
`--model cnn --target rank --loss corr`：

| 配置 | 参数量 | best val IC | 最佳 epoch | ICIR | ICIR_ann | t |
| --- | --- | --- | --- | --- | --- | --- |
| 随机 batch（无对齐） | 187,074 | **0.0477** | 4 | 0.3980 | 12.15 | +12.15 |
| 截面 batch（损失对齐，无注意力） | 187,074 | 0.0402 | 4 | 0.3355 | 10.24 | +10.24 |
| 截面 batch + 交叉注意力 | 393,538 | 0.0426 | 27 | 0.4004 | 12.22 | +12.22 |
| 分组大 batch + 交叉注意力 | 393,538 | 0.0436 | 17 | 0.4144 | 12.65 | +12.65 |

> 说明：四组同 seed 42、同数据口径，仅 batch 组织方式与模型结构不同。
> 第三组对应上一轮 xsec 结果，原始日志见 [raw/full_xsec_ab.log](./raw/full_xsec_ab.log)。
> 第四组为「大 batch 内跨截面分组」方案，见下文归因。

## 隔离变量归因（关键结论）

把「batch 组织方式」与「交叉注意力」拆开：

| 对比 | ΔIC | 归因 |
| --- | --- | --- |
| 截面 batch vs 随机 batch | 0.0402 − 0.0477 = **−0.0075** | 单截面 batch **本身有害**（梯度噪声） |
| xsec vs 截面 batch | 0.0426 − 0.0402 = **+0.0024** | 交叉注意力**有效**，但被 batch 拖累 |
| 分组大 batch vs 截面 batch | 0.0436 − 0.0426 = **+0.0010** | 分组大 batch 进一步**回收**了部分梯度稳定性 |

**结论**：

1. **交叉注意力是有效模块**（同样截面 batch 下 +0.0024，ICIR 0.3355→0.4004
   显著改善）。此前「注意力被残差绕过」的猜测**不成立**。
2. **单截面 batch 是负贡献**：单截面 batch（约 900–1000 只）即便
   `accum_steps=4`，梯度噪声仍明显高于随机大 batch，收敛到更差的解
   （0.0402 < 0.0477）。
3. **分组大 batch 部分修复**：多截面拼大 batch（~2048 只）+ 分组注意力 +
   分组损失，比单截面 xsec 再 +0.0010，ICIR 升至 0.4144（全组最优）。
4. **但净效果仍低于随机 batch baseline**（0.0436 < 0.0477）：说明
   「损失对齐」带来的收益 < 「大 batch 梯度稳定性」的损失，在单频 bar30m
   这个弱信号任务上，**随机大 batch 的梯度稳定性比损失对齐更重要**。

## 修正后的方向

- **✅ 已完成：分组大 batch + 交叉注意力**（本记录第四组）：
  多截面拼大 batch（~2048 只），注意力用 block-diagonal mask 按截面分组，
  损失用「组内 soft-IC 再跨组平均」。比单截面 xsec 再 +0.0010（ICIR 全组最优），
  但仍未超过随机 batch baseline。
- **⚠️ 关键取舍（单频 bar30m）**：随机大 batch 的梯度稳定性 > 损失对齐的收益。
  交叉注意力 + 分组损失在**弱信号单频**任务上净效果为负（−0.0041 vs baseline）。
- **多频融合是更现实的出路**：在 `StockTransformerMF`（多频提交包）上做共享
  截面注意力。多频下股票相对强弱信号更强（提交包多频 IC≈0.078 远高于单频
  0.047），截面注意力可能带来更大的绝对增量。这是下一步主攻方向。
- **若继续单频**：可尝试「随机大 batch + 分组损失（无需完整截面）」，
  即普通随机 batch 但把损失按 `(day, minute)` 分组求 soft-IC —— 保留大 batch
  梯度稳定性，同时让损失对齐评估口径。
