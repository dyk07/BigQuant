# 换手正则 λ 扫描 + 命中率修复

- **日期**：2026-10-20
- **模型**：`submissions/cnn_3f_1019_newlabel_xsec_amp` 的 `StockTransformerMF`（三频）
- **实验设置**：关 XSEC（隔离变量）、AMP fp16、独立配对 batch（100% 命中）
- **规模**：6 个月 smoke（train=202307..202310，val=202311..202312），seed=42

## 背景：换手正则实现缺陷

原实现的换手 loss 只在 `cur` 与 `next` 被随机 perm 打散到**同一个 batch** 时才触发：

```python
same = bcur == bnxt  # cur 与 next 落在同一 batch 才算命中
```

实测命中率（`_check_turnover.py`）：

| 指标 | 值 |
| --- | --- |
| 样本 N（2 个月） | 283,804 |
| 配对总数 | 247,830（87.3%） |
| **随机 perm 同 batch 命中** | **3,490（1.41%）** |

全量 48 个月（~700 万样本）命中率会进一步跌到 ~0.06%。即 λ=0.01 的名义强度被稀释几十倍，
换手正则实际上"偶然触发"而非"稳定生效"。

## 修复：独立配对 batch

训练每个 epoch 末尾追加一个**独立配对 step**：直接采样 k 对 `(cur, next)`（k=min(n_pair, batch/2)），
单独做一次前向，换手 loss `λ·(1 - corr(p_cur, p_next))` 100% 命中，且不扰动主损失方向。

- 训练函数新增 `lam_turnover` 参数（覆盖 config.LAMBDA_TURNOVER）
- 新增 `_eval_turnover`：验证集换手指标（同股票相邻截面因子排名变化均值，越低越好）
- `train_and_save(..., lam_turnover=lam)` 透传

## 实验结果（6 个月 smoke）

| λ | best val_IC | val_turnover（末尾 epoch） | 耗时 |
| --- | --- | --- | --- |
| 0.0（无换手） | +0.0966 | 0.24~0.27 | 10.5min |
| **0.005** | **+0.0983** | 0.16~0.23 | 8.4min |
| 0.02 | +0.0972 | 0.18~0.23 | 8.2min |
| 0.1 | +0.0956 | 0.17~0.26 | 10.6min |

## 结论

1. **λ=0.005 为当前最优点**：IC 最高（0.0983），且换手略低于 λ=0。
2. **换手正则对 IC 的影响很小**（0.005→0.1 仅 −0.0027）：独立配对 batch 修复后，
   换手惩罚温和、不再破坏主损失方向（对比修复前带 XSEC 时，换手会显著拖累 IC）。
3. **换手下降幅度有限**：val_turnover 未随 λ 单调下降。当前"相邻截面 corr"形式对换手
   约束力偏弱，可能因为：
   - `_turnover_next` 只配对**同日内**相邻采样截面（30min 网格），间隔较长，
     信号变化主要由 30min 跨度的信息更新驱动，而非高频抖动；
   - `1 - corr` 只约束**方向一致**，不约束**幅度一致**，排名小幅漂移不会被罚。
4. **真正的大头是关掉 XSEC**：val_IC 从带 XSEC 的 0.0767 跃升到 0.0983（+0.0216），
   再次印证 XSEC 是回退主因。
