## 回退根因分析

### 排除项：标签方向
- 用户确认新方向（`end_price/vwap - 1`）正确，故**不是** 10-18 改向导致。
- git 证据也支持：高分版（b5212aa，10-17）与最新版 predict 的差异只有
  XSEC sec_ids 传参与撤销取负，方向一致性无问题。

### 头号嫌疑：XSEC 交叉注意力 + 换手 loss（10-18 引入）
- 高分版 = `b5212aa` 的干净三频基线（无 XSEC、无换手、hidden64）。
- 最新版 = 加了 `use_xsec=True` + `use_turnover=True`(λ=0.01) 的三频。
- 本地 v6 记录已显示该组合是**负贡献**：val_IC 0.0782 → 0.0757。
- 公榜进一步放大为 0.0886 → 0.0642（−0.0244），说明：
  - XSEC 的 O(N²) 截面注意力 + 分组 corr loss 可能**破坏了大 batch 的梯度稳定性**
    （v5 单频实验已证「梯度稳定性 > 损失对齐」）。
  - 换手 loss λ=0.01 虽小，但会**改动主损失方向**，使模型为平滑换手而牺牲 IC。

### 次嫌疑：AMP 精度
- AMP 本地 val_IC 0.0767 与 fp32 0.0757 一致，无精度损失，基本排除。

## 结论与建议

1. **回退到高分基线**（`cnn_3f_1017_baseline_highscore`）是当前最安全的选项：
   它对应 ic_mean 0.0886 的干净三频，无 XSEC/换手的干扰。
2. 若想保留 XSEC/换手，需**隔离验证**：分别关掉 XSEC、关掉换手，各跑一次
   全量对拍，定位是哪个模块导致 −0.0244。
3. 换手率 0.6583 虽高（相对其他项是短板），但**不能以牺牲 ic_mean 0.0244 的
   代价去降换手**——五项各 20% 加权，ic_mean 的损失更大。
