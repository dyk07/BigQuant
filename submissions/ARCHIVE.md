## 说明

- **高分版（ic_mean 0.0886）尚未定位到具体 commit**：用户提供的两个分数
  （10-09 高分 / 最新低分）中，高分对应的确切提交待确认。当前归档覆盖了
  git 里 cnn_3f 权重的全部 3 个实质版本。
- `cnn_3f` / `cnn_2f` / `cnn_1f_bar30m` 三个**不带日期后缀**的目录 = 当前
  活跃开发版（可直接提交）。
- 带日期后缀的目录 = 历史快照，仅供回滚参考，**不要直接提交**。

## 已知事故

- **10-19 误删**：AMP commit（`7f278cf`）曾误删 `cnn_2f` 与 `cnn_1f_bar30m`，
  已从 `68c44be` 恢复。归档脚本 `_tools/_archive_version.py` 可复现任意
  commit 的完整包。

## 归档方法

```bash
python submissions/_tools/_archive_version.py <commit> <name> <pkg_subdir>
```

从 git 仓库导出 `<commit>` 时刻的 `submissions/<pkg_subdir>/` 全部文件到
`submissions/<name>/`。
